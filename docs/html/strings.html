Mixing this category

Starting points for every patch here. Each patch's own notes cover what's different about it.

  • High-pass at 150-200 Hz; low sections less, around 80-100 Hz.
  • Dip 300-500 Hz if they thicken up, and shelve the top down if they get wiry.
  • Use little compression, as they're already even. Sidechain gently in a dense track.
  • Wide chorus suits high sections; keep low sections nearer the centre.
  • Share a hall-style reverb send with the pad so they sit in the same space.

Performance

Play sustained chords. It's a machine rather than an orchestra, so don't try to phrase it like one.

How to use it

Chord beds in retro tracks, doubled with a pad, or as a countermelody in the chorus.

Mixing

  • HP 1 is already thinning the lows, but a high-pass at 200 Hz won't hurt.
  • Add a small plate, not a big hall: it should sound like a record, not a concert.
  • A lift around 5 kHz adds classic sheen.
  • Built-in chorus: part of this sound, so keep it. Built-in reverb: turn it off if you're using your own.

Pairings

  • Sunset SoloSoft shimmer behind a singing lead.
  • Funk guitarThe classic disco string and guitar arrangement.

Tweak it

  • Chorus Rate to 5.0A slower, calmer ensemble.
  • ENV T1 (attack) to 2.5A faster attack, for rhythmic string parts.
  • HPF to OffA fuller, warmer tone.
