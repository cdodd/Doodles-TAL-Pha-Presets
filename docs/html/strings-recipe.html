Building Ensemble Sunset from init

A string machine is simpler than it sounds: one saw and a very fast chorus. This recipe shows why those two things are enough, and how a thin low end makes it read as strings instead of a pad.

Setup

Choose Reset Parameters, then loop four-note chords with one chord per bar.

Each step's preview adds to the one before. Measurements compare it with the previous step.

  1. Set the level first

    • Volume5.0→to3.9

    Stacked chords add up fast, so set a sensible level before making decisions. Init's single saw is already the right waveform: a bowed string makes a roughly saw-shaped wave.

    Listen for: A plain, bright, organ-like chord.

  2. Make it bowed

    • Env T1 (attack)0.0 (about 1 ms)→to4.2 (about 165 ms)
    • Env T3 (decay)0.0 (about 10 ms to -20 dB)→to5.0 (about 678 ms to -20 dB)
    • Voices6→to8

    A bow takes time to catch the string. An attack of about 170 ms is what stops it sounding like an organ. More voices leave room for the release you'll add next.

    The other choice: Slow Bow goes up to about a second, for a swell that takes a whole bar. Staccato Run goes down to 15 ms, for short strokes.

    Listen for: Each chord now has a soft entry.

    • Time to half level: 0 ms → 100 ms

  3. Let the notes ring on

    • Env T4 (release)0.0 (about 10 ms to -20 dB)→to5.0 (about 778 ms to -20 dB)

    Strings keep ringing after the bow lifts, and in a room you always hear some of that. A longer release also hides the joins between chords.

    Listen for: Chord changes overlap a little.

    • Tail after note-off: 17 ms → 600 ms

  4. Remove the body

    • HPFOff→toHP 1

    This is what sets a string machine apart from a pad. HP 1 takes out the low-end weight and leaves a lighter, more nasal tone. It also makes room for the bass.

    The other choice: Silver Screen leaves the low end in, for a big orchestral section rather than a machine.

    Listen for: Thinner and lighter: it sounds less like a synth pad and more like strings.

    • Energy below 150 Hz: 2% → 2%

  5. Trim the top

    • VCF Cutoff10.0 (about 21726 Hz at C4)→to7.4 (about 3295 Hz at C4)
    • VCF Key follow0.0→to3.0

    Real strings have less extreme top end than a raw saw. A cutoff near 3 kHz takes off the fizz but stays bright. Unlike a pad, it should stay airy.

    Listen for: Less fizzy, still bright.

    • Brightness: 4,817 Hz → 1,334 Hz

  6. Add the chorus

    • ChorusOff→toOn

    At its default rate the chorus adds width, as on a pad. That's already nicer, but it doesn't yet sound like many players.

    Listen for: Wide, and much more lush. Compare it with the next step.

    • Stereo width (side/mid): 0.00 → 0.58

  7. Speed up the chorus

    • Chorus Rate5.0→to7.8

    This is the key decision. A fast chorus makes many tiny pitch changes at once, like an ensemble of players who aren't quite together. It's the whole trick of a string machine.

    The other choice: Rain City keeps the chorus slow for a calmer, darker section.

    Listen for: A quick shimmer. It should now sound like the string machine on an old record.

    • Stereo width (side/mid): 0.58 → 0.59

  8. Finish it

    • MW to VCF0.0→to1.5
    • MW to DCO LFO1.0→to0.0
    • Reverb mixOFF→to-0.70
    • Reverb size8.0→to5.0

    A small room suits a record, where a big hall would suggest an orchestra. The wheel gives you a gentle lift. That's the finished Ensemble Sunset.

    Listen for: In this preview the wheel rises across the second half, and the strings open up.

    • Wheel up vs wheel down brightness: 1.2x → 1.8x

What to take away

  • Chorus speed makes a big difference to character: slow gives width, and fast gives an ensemble.
  • Removing low end is often what makes a sound read as strings rather than a pad.
  • A bow can't start instantly, so even fast string parts need a little attack.
