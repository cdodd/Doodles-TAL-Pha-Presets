Building Outrun Sixteenths from init

A good arp is less about the pattern than about making each note short and distinct. This recipe builds the engine of an outrun track, and shows why envelope shape matters more than pitch.

Setup

Choose Reset Parameters and hold a four-note chord for a bar at a time. Run your project at any tempo; the arp will follow it.

Each step's preview adds to the one before. Measurements compare it with the previous step.

  1. Start from init

    A sustained saw through an open filter, with no arp yet. It's a chord.

    Listen for: A static, buzzy chord.

  2. Turn on the arp

    • Arp modeOff→toUp
    • Arp syncNo sync→toHost sync
    • Arp Rate1/16→to1/16
    • Arp range2 oct→to2 oct
    • Voices6→to6

    Up, 16th notes, two octaves, and host sync so it follows your project. But with init's full-sustain envelope, every note runs straight into the next one. Listen for how little rhythm that gives you.

    The other choice: Down feels calmer, as in Cascade. Random feels nervous, as in Random Terminal. Up is the one that feels like forward motion.

    Listen for: Notes change, but it's a stream rather than a rhythm: there are no gaps.

  3. Make each note short

    • Env T3 (decay)0.0 (about 10 ms to -20 dB)→to2.8 (about 107 ms to -20 dB)
    • Env L3 (sustain)10.0→to0.0

    This is the key decision. With a decay of about 100 ms and no sustain, every note dies away before the next, which is where the pulse comes from. The VCA is left in Normal mode on purpose, so that the level falls as well.

    The other choice: Sequencer Drive uses Gate mode instead, so the amp stays open and only the filter pulses. That sounds more mechanical.

    Listen for: Now it's an arp: separate notes with a clear pulse.

    • Held level: -1 dB from peak → -7 dB from peak
    • Note rate: 4.2 per second → 6.3 per second

  4. Darken the filter

    • VCF Cutoff10.0 (about 21726 Hz at C4)→to4.2 (about 252 Hz at C4)
    • VCF Key follow0.0→to4.0

    Closing the filter makes room for the envelope to open it on each note. Key follow keeps the high notes of the two-octave run from going dull.

    Listen for: Duller and quieter: too dark, for now.

    • Brightness: 4,344 Hz → 383 Hz

  5. Open the filter on each note

    • VCF Env0.0→to3.6
    • VCF Res0.0→to1.5

    The same envelope that's shaping the level now sweeps the filter too, so every note gets a tiny 'pew'. A little resonance gives that sweep some character.

    Listen for: A snappy, plucked quality on every note. This is the sound.

    • Brightness: 383 Hz → 1,682 Hz

  6. Soften the note endings

    • Env T4 (release)0.0 (about 10 ms to -20 dB)→to2.0 (about 50 ms to -20 dB)

    A short release means notes overlap very slightly, so the pattern doesn't sound clipped. Keep it short, or you'll lose the gaps you just made.

    Listen for: A little smoother, still clearly separated.

    • Tail after note-off: 5 ms → 75 ms

  7. Add an echo

    • Delay mixOFF→to-0.76
    • Delay Time1/4→to1/8
    • Delay feedback2.0→to2.0

    A quiet 1/8 echo thickens the pattern. It's synced to the tempo, so it stays on the same grid as the arp. Keep it low: too much will blur the 16ths. At its default spread the delay stays centred, so move Delay spread away from 0.00 if you want it wider.

    Listen for: Slightly thicker, with no change in width.

    • Stereo width (side/mid): 0.00 → 0.00

  8. Set up the wheel

    • MW to VCF0.0→to3.0
    • MW to DCO LFO1.0→to0.0

    An arp is a great place for a build, and the wheel opens the filter for one. Turning off the default vibrato is important here, as it would make a fast pattern sound out of tune.

    Listen for: In this preview the wheel rises across the second half, for a simple build.

    • Wheel up vs wheel down brightness: 1.0x → 2.9x

  9. Set the level

    • Volume5.0→to8.5

    Short notes measure quieter than sustained ones, so this needs more volume to reach the same loudness as other presets. That's the finished Outrun Sixteenths.

    Listen for: The finished patch.

    • Loudness: -27.1 LUFS → -18.0 LUFS

What to take away

  • An arp needs gaps. Without a short envelope, the notes run together into a wash.
  • Use host sync, so that the arp, echoes and project all stay locked at any tempo.
  • A short sustain-free envelope drives both level and filter, which makes one control do the job of two.

Where to go next

Starting points for moving from Outrun Sixteenths to another patch in the bank:

  • Digital RainTry adding VCF LFO 3.2 with an S&H wave, synced to 1/16, for a random tone on every note.
  • Dotted EighthSlow the arp to 1/8, change the delay to 1/8. and raise its mix to -0.16.
  • CascadeSwitch the mode to Down, the range to 3 octaves and the wave to Pulse PW, then add the chorus.
