Building Neon Pluck from init

A pluck is one of the simplest sounds to build, and one of the most useful. It's the mirror image of the Bass recipe: here you want the shared envelope to close the amp and filter together, so that the note dies away whether the key is held or not.

Setup

Choose Reset Parameters and loop a broken-chord pattern of 8th notes around A4, with some velocity variation.

Each step's preview adds to the one before. Measurements compare it with the previous step.

  1. Start from init

    A sustained saw through an open filter.

    Listen for: A buzzy organ-like line.

  2. Make every note die away

    • Env T3 (decay)0.0 (about 10 ms to -20 dB)→to4.0 (about 304 ms to -20 dB)
    • Env L3 (sustain)10.0→to0.0

    This is the key decision. With no sustain, a note fades whether the key is held or not, which is how a plucked string behaves. Decay of about 300 ms is a useful middle ground.

    The other choice: A decay of 2.0 gives Pulse Tick's tiny tick. A decay of 6.2 gives Synth Harp's long ring.

    Listen for: It already sounds plucked, if a bit harsh.

    • Held level: -1 dB from peak → -60 dB from peak

  3. Let notes ring past the key

    • Env T4 (release)0.0 (about 10 ms to -20 dB)→to3.4 (about 168 ms to -20 dB)
    • Voices6→to6

    A real string doesn't stop when your finger lifts. Without release, short notes cut off early. Six voices let those tails overlap.

    Listen for: Short notes now have a natural tail.

    • Tail after a very short note: 7 ms → 407 ms

  4. Close the filter

    • VCF Cutoff10.0 (about 21726 Hz at C4)→to4.5 (about 320 Hz at C4)
    • VCF Key follow0.0→to5.0

    A plucked string is bright at first and darkens as it dies. To hear that, the filter needs to start closed, so that the envelope can open it. Key follow keeps high notes bright enough.

    Listen for: Duller, with no snap: the next step fixes it.

    • Brightness: 4,790 Hz → 564 Hz

  5. Add the snap

    • VCF Env0.0→to3.8
    • VCF Res0.0→to1.0

    A big, fast filter sweep from the same envelope gives the snap of the pluck. A little resonance makes it more defined.

    Listen for: A clear 'pew' on every note: it's a pluck now.

    • Brightness: 564 Hz → 2,604 Hz
    • Filter sweep: 0.0 octaves → 1.9 octaves

  6. Add touch sensitivity

    • VCF Env modeNormal→toNormal-Dynamic

    Normal-Dynamic makes harder notes snap brighter. In a repeating pattern, this stops every note sounding the same and gives you an easy way to shape a phrase.

    Listen for: Accented notes snap brighter than others.

    • Hard note vs soft note brightness: 1.0x → 2.5x

  7. Add width and echo

    • ChorusOff→toOn
    • Chorus Rate5.0→to5.0
    • Delay mixOFF→to-0.68
    • Delay Time1/4→to1/8.
    • Delay feedback2.0→to2.2
    • Delay spread+0.00→to+3.00

    Chorus gives width, and a short dotted 8th echo spreads each note into the gaps between others. This turns a simple line into something that sounds more complicated than it is.

    The other choice: Echo Street goes much further with the delay, so the echoes become part of the melody.

    Listen for: Much bigger, with a rhythm in the echoes.

    • Stereo width (side/mid): 0.00 → 0.62

  8. Set up the wheel

    • MW to VCF0.0→to2.0
    • MW to DCO LFO1.0→to0.0

    The wheel opens the filter, for a brighter section. The default vibrato is turned off, as it would make short notes sound unstable.

    Listen for: In this preview the wheel rises across the second half, and the pluck gets brighter.

    • Wheel up vs wheel down brightness: 1.0x → 1.9x

  9. Set the level

    • Volume5.0→to6.3

    This takes it to the same loudness as the other presets. That's the finished Neon Pluck.

    Listen for: The finished patch.

    • Loudness: -23.7 LUFS → -19.9 LUFS

What to take away

  • With sustain at zero, a single envelope closes both amp and filter together. This is why a pluck is so easy on this synth.
  • Decay time decides what the sound is: tick, pluck, or key, all with the same settings otherwise.
  • Velocity to filter makes a hand-played part feel alive.

Where to go next

Starting points for moving from Neon Pluck to another patch in the bank:

  • Pulse TickTry swapping to Pulse 25%, opening the filter to 6.8, and shortening the decay to 2.0.
  • Synth HarpLengthen decay and release to about 6.0, and add Env Key follow 4.5 so that high notes die faster.
  • Resonant BlipRaise resonance to 6.8, shorten the decay to 2.8 and remove the chorus.
