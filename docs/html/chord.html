Chord and Stab

10 patches. Control values are as shown on the plugin panel. Times and frequencies come from measurements of the plugin.

New to this category? Build a patch from init, step by step, hearing each decision.

Mixing this category

Starting points for every patch here. Each patch's own notes cover what's different about it.

  • High-pass at 100-200 Hz, or about 100 Hz for heavy riffs.
  • Lift 1-3 kHz for bite, or dip it to make room for the lead.
  • Compress stabs so they hit evenly. Sidechain sustained chords to the kick.
  • One key plays a parallel chord, so width comes from chorus and delay. Check it in mono.
  • Delay throws on the last stab of a phrase suit these well.
