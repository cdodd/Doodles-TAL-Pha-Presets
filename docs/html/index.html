Doodles TAL-Pha Presets

100 synthwave-style presets for TAL-Pha, an Alpha Juno II emulator synth by TAL Software. Each one is documented so you can see how the sound works and how to use it. New to the synth? Start with the field guide.

These presets and this documentation were generated using Claude Opus 5.5.

Install

The steps are the same on Linux, macOS and Windows.

  1. Download Doodles-TAL-Pha-Presets.zip and extract it.
  2. In TAL-Pha, open the preset browser and click Open Folder….
  3. Copy the Doodles folder into the folder that opens.
  4. In the preset browser, press Reload and filter by the Doodles bank.

If you've cloned the repo, skip step 1 and copy presets/Doodles instead.
