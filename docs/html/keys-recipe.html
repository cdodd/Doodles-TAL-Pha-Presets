Building Eighty-Four Tines from init

This synth can't do FM, but the 80s digital electric piano is such an important sound that it's worth getting close. This recipe builds it from two separate layers: a soft body and a metallic tine that's only heard at the start of a note.

Setup

Choose Reset Parameters and loop some gentle chords around C4, with velocity variation. Harder notes will show the tine.

Each step's preview adds to the one before. Measurements compare it with the previous step.

  1. Set the level first

    • Volume5.0→to3.8

    Chords add up, so set a sensible level first. Then you can judge each change for what it does, rather than how loud it is.

    Listen for: A plain, buzzy saw chord.

  2. Replace the saw with a soft body

    • DCO SawSaw→toOff
    • Sub waveSquare -1 oct (panel label: OFF)→toSquare -1 oct (panel label: OFF)
    • Sub level0.0 / 3→to2.2 / 3
    • Octave+0→to+1

    An electric piano's body is rounded and simple, nothing like a saw. A square from the sub oscillator gives you that. The sub sits an octave below the DCO, so Octave +1 brings it back up to the note you're playing.

    The other choice: Warm Tines uses a filtered square at the played pitch and leaves out the tine completely, for a mellower electric piano.

    Listen for: Hollow and low. The panel says the sub is 'OFF', but it's really a square.

    • Brightness: 4,302 Hz → 3,778 Hz

  3. Make it die away

    • Env T3 (decay)0.0 (about 10 ms to -20 dB)→to6.2 (about 1.6 s to -20 dB)
    • Env L3 (sustain)10.0→to1.0
    • Env T4 (release)0.0 (about 10 ms to -20 dB)→to4.5 (about 419 ms to -20 dB)
    • Voices6→to8

    Struck instruments fade even while the key is held. A decay of about 1.5 seconds with a little sustain gives you a natural fade. More voices let the ringing notes overlap.

    Listen for: Each chord fades away, like a struck key.

    • Held level: -0 dB from peak → -8 dB from peak
    • Tail after note-off: 10 ms → 600 ms

  4. Add the tine

    • DCO PulseOff→toSquare
    • Pulse SyncOff→toOn
    • Pulse Tune+0 st→to+24 st
    • Pulse Env mod+0.00→to+0.15
    • Pulse Volume10.0→to4.2

    This is the key decision. A pulse hard-synced two octaves up makes a metallic set of overtones similar to an FM tine. A small pulse envelope makes the tone change as the note fades. You won't hear this as a separate tine yet: it's on all the time.

    The other choice: Try other Pulse Tune values such as +19 for a different metallic ratio. Real FM has more variety; this has its own charm.

    Listen for: A constant metallic buzz over the body. Too much for now.

    • Brightness: 3,817 Hz → 5,295 Hz

  5. Hide the tine behind a filter

    • VCF Cutoff10.0 (about 21726 Hz at C4)→to4.2 (about 252 Hz at C4)
    • VCF Key follow0.0→to6.0

    With the filter closed, the high tine disappears, leaving only the body. Key follow makes higher notes brighter, as on a real keyboard.

    Listen for: A soft, rounded electric piano with almost no tine.

    • Brightness: 5,295 Hz → 321 Hz

  6. Reveal the tine at the attack

    • VCF Env0.0→to4.2

    Now the filter opens for an instant, so the tine is only heard at the very start of the note. This is the same fade as in the previous steps, and it's what makes it sound struck. The same principle works for bells and clavs.

    Listen for: A glassy 'ting' at the start of each note, then the soft body.

    • Filter sweep: 0.0 octaves → 1.7 octaves
    • Brightness: 321 Hz → 2,819 Hz

  7. Let velocity control the tine

    • VCF Env modeNormal→toNormal-Dynamic

    On a real digital EP, playing harder brings out more of the tine. Normal-Dynamic does the same, and it's what makes it feel like an instrument.

    Listen for: Soft chords are mellow, and accents bring out the bell-like edge.

    • Hard note vs soft note brightness: 1.0x → 4.2x

  8. Add the 80s

    • ChorusOff→toOn
    • Chorus Rate5.0→to4.8

    Almost every 80s electric piano you can think of had chorus on it. It adds width and hides the difference between this sound and the real thing.

    Listen for: Wide and glassy: that's the sound.

    • Stereo width (side/mid): 0.00 → 0.58

  9. Finish it

    • MW to DCO LFO1.0→to0.6
    • LFO Rate0.95 Hz→to5.03 Hz
    • Reverb mixOFF→to-0.72

    A little reverb, and a trim to the wheel's vibrato. Init already sends the wheel to vibrato at 1.0, which is too wide for an electric piano, so 0.6 is plenty. That's the finished Eighty-Four Tines.

    Listen for: In this preview the wheel rises across the second half, adding vibrato.

    • Vibrato with wheel up: 59 cents → 33 cents

What to take away

  • Sync is a good stand-in for FM's metallic overtones, within limits.
  • Filter envelope can be used to reveal a layer briefly: the tine is only audible while the filter's open.
  • Layering a body and an attack is a useful way to build almost any keyboard sound.

Where to go next

Starting points for moving from Eighty-Four Tines to another patch in the bank:

  • Warm TinesTry removing the sync layer, returning Octave to 0, and using a filtered Square at the played pitch with VCA Normal-Dynamic.
  • Glass ChimeUse Saw 4 instead, set the HPF to HP 2, open the filter and remove sustain.
  • Funk ClavUse Pulse 25%, HP 2, add resonance and shorten the decay to 3.2.
