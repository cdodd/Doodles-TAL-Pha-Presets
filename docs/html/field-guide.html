Field guide

How TAL-Pha is put together, what it can't do and how to get around that, and what values to start from for each type of sound. For measured numbers, see the control reference.

Signal flow

DCO  ->  HPF  ->  VCF  ->  VCA  ->  effects
saw       |      24 dB      |       chorus, EQ, delay, reverb
pulse     |
sub       |      One envelope drives pitch, filter and amp.
noise     |      One LFO drives pitch and filter.

Each voice runs through the same path. PWM has its own rate control, separate from the main LFO.

What it can't do, and how to get around it

Most of the decisions in this bank come from these limits. If a patch's settings seem odd, it's probably working around one of them.

Limit Workaround See it in
One envelope for pitch, filter and amp VCA Gate: the amp follows the key, leaving the envelope to the filter and pitch Bass recipe
Envelope can't fall and then rise in plain ADSR terms Use the extra stage: T1/L1, T2/L2, T3/L3 can go in either direction Sforzando
LFO can't reach the amp, so no tremolo Move the filter instead, with a deep LFO; a square wave chops the sound Gated Chord
No sidechain inside the synth A synced saw LFO on the filter gives a similar pump Pulse Bloom
One filter Use the HPF for the low end and the VCF for the top; the bell EQ can add a formant Retro Choir
Not an FM synth Sync adds metallic overtones; open the filter only at the attack, to reveal them briefly Keys recipe
One oscillator per voice Pulse Tune and Fine make the pulse a second source; chorus and unison add more Chrome Octave
Pitch envelope leaves held notes off pitch with sustain above 0 Set sustain to 0 with VCA Gate, so the note holds and the pitch returns Razor Fifth
Chorus has no low-frequency limit Keep it off low patches, or narrow the lows in your mix Velvet Bass

The controls, in the order you'd reach for them

  1. Range, wave and voices. Which register and how many notes? Mono for bass and most leads; 6-10 voices for pads and keys, as releases overlap.
  2. VCA mode. Should the level follow the envelope (pluck, pad) or the key (bass, organ)?
  3. Envelope times and sustain. This is usually what defines the instrument type: see the table below.
  4. Filter cutoff and envelope amount. Start darker than you'd expect. Envelope amount is strong, and does nothing useful if sustain is at full.
  5. Velocity mode. Normal-Dynamic is one of the strongest tone controls on the synth.
  6. Motion. PWM, a slow LFO on the filter, or delayed vibrato.
  7. Width. Chorus or unison, keeping low notes in mind.
  8. Space. Delay and reverb. The delay is centred until you move its spread away from 0.00.
  9. Wheel. Init sends the wheel to vibrato, which is usually too wide. Set it to what the patch actually needs.

Reading down the table shows what separates the categories. Bass leans on VCA Gate. Arps, plucks and keys have little or no sustain. Pads and strings sustain fully, with long attacks and releases, and pads have a darker filter than strings.

Learning path

  1. Follow the "Build from init" pages in the plugin. Each category has one, and each builds a patch from the init sound a step at a time, so you can hear what every change does. Different categories teach different parameters, so use them to learn the controls you're curious about. Start with Bass, which shows how VCA Gate lets the single envelope sweep the filter while the amp holds the note.
  2. Listen to the sound gallery, so that you know what each wave and control sounds like.
  3. Follow the Pluck recipe, the mirror image of the bass, then Pad for motion and width.
  4. Pick a starter kit and write a short track, then use the Reaper cheat sheet to mix it.
  5. Choose a preset you like and change one thing at a time using its "Tweak it" notes.
